# Private Data Notice

This transfer package is meant for another branch to customize.

The package intentionally excludes:

- Real teacher roster.
- Real student roster.
- Production `.env.local`.
- Vercel `.vercel` project folder.
- Supabase project secrets.
- Redis / Upstash credentials.
- Local temporary output folders.
- Local generated-image cache.

The remaining IDs, teacher names, branch names, rooms, and domains are generic placeholders. Replace them with the new branch's own data during setup.
