# Collaboration Handoff

This starter package now uses the root-level `README.md`, `HANDOFF.md`, and `AGENTS.md` as the source of truth for new branch setup.

Use this file only as a pointer:

1. Read `../README.md`.
2. Read `../HANDOFF.md`.
3. Read `../AGENTS.md`.
4. Configure the new branch's own Supabase, Vercel, Redis, logo, room names, teacher list, and student list.

Do not reuse another branch's private project references, credentials, or rosters.
